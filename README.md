# 開工吧！社畜人生！餐廳 POS 模擬器

以單一 `index.html` 提供的餐廳點餐與收銀小遊戲。畫面、樣式與互動程式都整合在同一檔案；開啟 `index.html` 即可遊玩。Tailwind CSS 與 Noto Sans TC 字型由 CDN 載入。

## 功能

- **每日任務與關卡挑戰**：累積完成訂單、解鎖關卡，並可重玩已完成關卡。
- **可愛客人與相簿**：接待不同職業與個性的客人，逐步解鎖客人資料。
- **Uber Eats 外送單**：隨機接收外送訂單，完成餐點後交付外送員。
- **豐富餐點菜單**：提供 85 種主食、小菜、甜點與飲品，並可依分類瀏覽。
- **餐廳服務評分**：依照是否送齊客人指定的主餐與飲品調整服務評分，並追蹤營業額。

每日任務進度與已解鎖客人會保存在瀏覽器的 `localStorage`。

## 使用方式

1. 在瀏覽器開啟 `index.html`。
2. 點選「迎接下一位客人」，查看內用或外送需求。
3. 從分類菜單加入客人指定的主餐與飲品。
4. 點選「送單並結帳」完成訂單；內用需要輸入客人付款金額。
