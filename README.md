# 餐廳 POS 收銀結帳模擬器 (Restaurant Cashier & Order Simulator v1.1)

一個互動式的餐廳收銀與點餐模擬系統，讓使用者扮演餐廳服務員，親身體驗前台點餐、核對顧客需求、計算金額與結帳的流暢流程！

🔗 **線上展示：** [Restaurant Cashier & Order Simulator](https://jasminechuang.github.io/cashier_stimulator/)

---

## 💡 功能特色

* **動態顧客點餐模擬**：點擊「迎接下一位客人」隨機接待顧客，接收顧客的口頭點餐需求。
* **分類點餐面板**：支援多樣化的品項分類檢視，包含：
  * **主食特餐**（如：招牌牛肉堡、奶油蘑菇義大利麵、夏威夷鮮蝦披薩、炙燒鮭魚排等）
  * **炸物小食**（如：黃金起司薯條、日式炸雞塊、酥皮濃湯等）
  * **手搖飲品**（如：黑糖珍珠鮮奶、經典冰美式、鮮榨柳橙汁、草莓奶昔等）
* **即時帳單計算**：點擊餐點自動加入當前客人的點餐清單，即時計算總計金額。
* **營業額與評分追蹤**：完成結帳後即時更新今日營業額，並連動服務生評分系統。

---

## 🚀 快速開始

1. 前往線上展示網頁：[https://jasminechuang.github.io/cashier_stimulator/](https://jasminechuang.github.io/cashier_stimulator/)
2. 點擊畫面中的 **[🔔 迎接下一位客人]** 按鈕開始接待第一位顧客。
3. 根據顧客的「口頭需求」，從右側分類菜單中點擊對應的餐點加入清單。
4. 核對無誤後，點擊 **[💳 送單並結帳]** 完成點餐流程！
