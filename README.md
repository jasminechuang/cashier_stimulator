# 餐廳服務員收銀機點餐模擬器 (Restaurant Cashier & Order Simulator)

一個以純前端網頁打造的餐廳點餐與收銀小遊戲。畫面、樣式與互動程式皆整合於單一 `index.html` 檔案中，透過 CDN 載入 Tailwind CSS 與 Noto Sans TC 字型，隨開隨玩！

線上展示：[Restaurant Cashier & Order Simulator](https://jasminechuang.github.io/cashier_stimulator/)

---

## 📋 主要功能

- **每日任務與關卡挑戰**：累積完成指定訂單數量以通過關卡，並支援關卡回顧與重玩已完成的關卡。
- **可愛客人相簿**：每次迎接新客人入座，即可認識不同的職業與個性，逐步解鎖豐富的客人相簿圖鑑。
- **台灣特色餐點菜單**：內建高達 85 種台灣在地主食、小菜、甜點與飲品，並支援分類快速瀏覽。
- **餐廳服務評分與營業額追蹤**：依照點餐正確率與結帳互動調整服務生評分，並即時追蹤今日營業額。
- **彈性結帳與優惠系統**：內用需手動輸入客人付款金額計算找零，並支援「全單 9 折」或「滿 $200 折 $50」等優惠折扣。
- **進度自動儲存**：遊戲內的關卡解鎖進度與已解鎖之客人資料會自動保存在瀏覽器的 `localStorage` 中。

---

## 🕹️ 使用方式

1. 在瀏覽器開啟 `index.html`。
2. 點選 **「🔔 迎接下一位客人」**，查看客人的內用或外送點餐需求。
3. 從右側的分類選單（主食、小菜、甜點、飲品）點擊對應餐點，加入收銀機結帳清單。
4. 核對客人點餐品項，確認金額與優惠後，點選 **「💳 送單並結帳」** 完成訂單。

---

## 🛠️ 技術架構

- **HTML5 / CSS3 / JavaScript** (Single File Architecture)
- **Tailwind CSS** (透過 CDN 載入進行介面排版與樣式設計)
- **LocalStorage API** (用於保存遊戲通關進度與客人解鎖狀態)
